# Datalook Studio

**Self-hosted, browser-based database management dashboard for teams.**

Datalook Studio lets you connect to PostgreSQL, MySQL, MongoDB, Redis, Cassandra, and more — all from a single web UI with role-based access control, encrypted credentials, and zero backend dependencies.

## Features

- :material-database: **11 database drivers** — PostgreSQL, MySQL, MSSQL, CockroachDB, ClickHouse, MongoDB, CouchDB, Redis, Cassandra, DynamoDB, SQLite
- :material-shield-account: **Role-based access control** — Admin, Editor, Viewer + custom roles with fine-grained permissions
- :material-lock: **Encrypted credentials** — AES-GCM encryption via Web Crypto API, credentials never stored in plaintext
- :material-server-off: **Zero backend** — Entire app runs in the browser, data persisted in IndexedDB
- :material-account-group: **Team-ready** — Shared connections with per-user grants, audit logging, admin console
- :material-code-braces: **SQL editor** — Syntax highlighting, query history, saved queries per database type
- :material-download: **Multi-format export** — CSV, TSV, JSON, and aligned text exports
- :material-file-cog: **YAML config** — Import/export connection configurations as YAML files
- :material-palette: **Customizable theming** — Light/dark mode with 6 accent colors
