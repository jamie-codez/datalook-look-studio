# Contributing

See the [CONTRIBUTING.md](https://github.com/datalook/studio/blob/main/CONTRIBUTING.md) file in the repository for full contribution guidelines.

## Quick summary

1. Fork & clone the repo
2. `pnpm install && pnpm dev`
3. Create a branch: `feat/my-feature`
4. Make changes, ensure `npx tsc --noEmit` and `pnpm build` pass
5. Open a PR targeting `main`

## Code of Conduct

All contributors must follow the [Code of Conduct](https://github.com/datalook/studio/blob/main/CODE_OF_CONDUCT.md).
