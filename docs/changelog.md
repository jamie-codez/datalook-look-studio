# Changelog

## 0.1.0

### Features

- Multi-engine database support (11 drivers)
- SQL editor with syntax highlighting and query history
- Data browser with sortable, exportable results
- Role-based access control (Admin, Editor, Viewer + custom roles)
- Shared and personal connections with per-user grants
- AES-GCM encrypted credentials at rest (Web Crypto API)
- IndexedDB persistence (meta, connections, queries, audit)
- YAML connection configuration import/export
- Multi-format data export (CSV, TSV, JSON, Text)
- Audit logging with JSON export
- Light/dark theme with 6 accent colors
- Server status monitoring per connection
- Datasource picker prompt for New Query / browse table
- Tabbed new connection dialog (Connection, Topology, Access)
- Settings sidebar navigation (Appearance, Account, System store, Server status, Notifications, Administration)
- Form input disabling on submit across all forms
- Docker containerization with multi-stage build
- MkDocs documentation site
